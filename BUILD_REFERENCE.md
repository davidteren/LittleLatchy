# Build Reference for LittleLatchy Plugin

This document provides a detailed explanation of the build process for the LittleLatchy plugin, as well as an overview of the plugin's structure.

## Build Process

The LittleLatchy plugin uses the JUCE framework and CMake for its build process. The following steps are involved in building the plugin:

1.  **Clone the repository:** The first step is to clone the LittleLatchy repository from GitHub.
2.  **Initialize and update git submodules:** The JUCE framework is included as a submodule in the LittleLatchy repository. This step initializes and updates the JUCE submodule.
3.  **Create a build directory:** A separate build directory is created to store the build artifacts.
4.  **Run CMake:** CMake is used to generate the build files for the project.
5.  **Build the project:** The project is built using the generated build files.

Alternatively, you can use the `build_all.sh` script to automate the build process. This script performs the following steps:

1.  Initializes and updates git submodules.
2.  Creates a build directory if it doesn't exist.
3.  Runs CMake to generate the build files.
4.  Builds the project using the generated build files.

## Plugin Structure

The LittleLatchy plugin has the following directory structure:

*   `.gitignore`: Specifies intentionally untracked files that Git should ignore.
*   `.gitmodules`: Defines the JUCE framework as a Git submodule.
*   `build/`: Contains the build artifacts generated by CMake.
*   `build_all.sh`: A script that automates the build process.
*   `CMakeLists.txt`: The main CMake file for the project.
*   `JUCE/`: Contains the JUCE framework.
*   `README.md`: Provides information about the project, including build instructions.
*   `Source/`: Contains the source code for the plugin.
    *   `PluginEditor.cpp`: The source code for the plugin's editor.
    *   `PluginEditor.h`: The header file for the plugin's editor.
    *   `PluginProcessor.cpp`: The source code for the plugin's processor.
    *   `PluginProcessor.h`: The header file for the plugin's processor.
    *   `PluginTests.cpp`: The source code for the plugin's tests.

## Dependencies

The LittleLatchy plugin has the following dependencies:

*   JUCE framework
*   CMake (3.15 or higher)
*   Platform-specific requirements:
    *   macOS: Xcode
    *   Windows: Visual Studio
    *   Linux: GCC/Clang and development libraries
